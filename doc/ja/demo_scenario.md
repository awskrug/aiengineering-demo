3. 環境変数
   - APIエンドポイント設定
   - GitHubトークン管理

### 14.3 GitHub Pages設定
```
GitHub CLIで設定を進めて。
```
1. GitHub CLI設定試行
   ```bash
   # API経由のPages設定試行
   gh api \
     -H "Accept: application/vnd.github+json" \
     -H "X-GitHub-Api-Version: 2022-11-28" \
     repos/awskrug/aiengineering-demo/pages \
     -f source='{"branch":"gh-pages"}'
   ```
   - APIベータ状態による制限事項確認
   - CLIによる直接設定不可を確認
2. 代替設定の実施
   ```bash
   # リポジトリをpublicに設定
   gh repo edit awskrug/aiengineering-demo --visibility public --accept-visibility-change-consequences
   
   # APIエンドポイントシークレット設定
   gh secret set VITE_API_ENDPOINT --body "https://api.todo.awskrug.dev"
   ```
3. 手動設定が必要な事項
   - GitHub WebインターフェースでSettings > Pagesへ移動
   - Sourceを'GitHub Actions'に設定
4. デプロイURL
   - https://awskrug.github.io/aiengineering-demo/

### 14.4 設定時の注意事項
- GitHub Pages APIはまだベータ状態
- CLIによる直接設定は現状未対応
- リポジトリは必ずpublicである必要あり
- GitHub Actionsワークフローがデプロイを担当
- Webインターフェース設定は初回のみ必要
